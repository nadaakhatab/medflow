MEDFLOW 3D PORTFOLIO

Open index.html in any modern browser.

This is a self-contained static portfolio website. No server, build step, or external JavaScript library is required.

Files:
- index.html
- styles.css
- app.js
- assets/ (product screenshots + hackathon image)

Tip: for the smoothest local experience, run a simple static server from this folder, for example:
  python -m http.server 8080
Then open http://localhost:8080
